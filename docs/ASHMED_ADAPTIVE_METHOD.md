# ASHMED_Adaptive：学习中心、独立尺度与零状态正则

本方法是用户授权的ASHMED方法修改探索，原实现与第三notebook均保留。代码：`R/methods/plugins/ashmed_adaptive.R`。它沿用原采样摘要、四状态结构、正态混合收缩、local FDR及q=0.05的平均local FDR筛选规则，修改替代效应字典和权重估计。它与原论文方法使用不同名称。

## 为什么修改

两套历史DGP的非零α、β具有明确方向，教学数据还是固定非零效应；原ASHMED的所有先验成分均以0为中心，H11中两个方差共用尺度j，难以同时描述弱α与强β。独立尺度虽增加灵活性，也使近零连续替代成分更容易与精确零状态混淆。实际初步开发中，“仅独立尺度”以及“同时保留零中心和学习中心”均出现明显FDR膨胀，全部记录并排除。

采用两个段各自学习的非零中心、多个方差及独立组合，减少错设；再用零状态正则稳定近零成分与状态概率的估计。具体强度在开发数据上比较后锁定，最终验证子集不用于选型。

## 1. 从观测摘要学习中心

对一段效应的观测x_i与已知采样方差v_i，拟合

\[
x_i\sim(1-p)N(0,v_i)+pN(\mu,v_i+t),\qquad t\ge0.
\]

使用观测标准误中位数标准化，两个分位数0.05/0.95、两个起始非零比例0.1/0.4，共四个确定起点，以最大观测似然选择。E步计算r_i为非零成分后验；ECM依次更新

\[
p^{new}=m^{-1}\sum_ir_i,\qquad
\mu^{new}=\frac{\sum_ir_ix_i/(v_i+t)}{\sum_ir_i/(v_i+t)},
\]

再对t≥0最大化加权正态对数似然，包括0边界。恢复原单位的中心μ。边际模型只用于学习字典中心，最终中介判断仍使用二维四状态模型；没有调用MLFDR的中介筛选结果。

两段分别得到μ_α、μ_β；marginal拟合的π与方差不是最终四状态权重。若任一中心距0不足0.5倍该段标准误中位数，采用原版ASHMED的同尺度模型回退，避免把缺乏识别的近零点质量强行标成非零效应。该规则仅依赖观测数据。

## 2. 非零中心多尺度字典

默认J=6，r=(0.25,0.5,1,2,4,8)，另含r=0的学习中心点质量。设

\[
u_j=(r_j\widetilde s_\alpha)^2,\quad v_l=(r_l\widetilde s_\beta)^2.
\]

主方法的各状态先验为：H00=原点点质量；H10的α~N(μ_α,u_j)、β=0；H01的α=0、β~N(μ_β,v_l)；H11的先验均值=(μ_α,μ_β)，两个方差独立组合。

默认ρ=0，H11的U_jl=diag(u_j,v_l)。因此正常学习分支有1+7+7+49=64个成分。可配置ρ及尺度；开发中的zero_anchor开关可额外纳入零中心替代字典，但最终配置以锁定文件为准。原H00及两轴的精确零定义保留。

多个尺度的权重可描述窄峰、分散效应和厚尾；状态内成分权重自由，H11可以使用与H10/H01不同的尺度组合。这个模型包含更多成分和更灵活的状态条件方差分布，与只用一个非零正态成分的MLFDR不同；当前简单DGP下，部分权重可能集中于少数成分，表现接近MLFDR是合理结果。

## 3. 零状态的Dirichlet形式正则

记联合成分权重w_k、状态质量π_s=Σ_{k∈s}w_k、边际密度L_ik=N2(hatθ_i;μ_k,S_i+U_k)。优化

\[
Q(w)=\sum_i\log\sum_kw_kL_{ik}
+\frac{\lambda}{3}(\log\pi_{00}+\log\pi_{10}+\log\pi_{01}).
\]

λ≥0为总零状态伪计数。正则鼓励保留三个复合零状态，强度是稳定化超参数；形式等价于状态Dirichlet密度，三个零状态参数1+λ/3，H11参数1。它保持q=0.05，并通过估计模型影响后验概率。

对于每个状态，c_s=λ/3（零状态）或0（H11）。加入只知道状态的虚拟观测进行EM增广，其更新为

\[
w_k^{new}=\frac{\sum_i r_{ik}+c_s w_k/\pi_s}{m+\lambda}.
\]

λ=0时退化为原ASHMED的联合权重EM；固定点也满足分层MAP的π更新与状态内ω更新。使用单调外推加速及顶点线搜索求解同一目标。

固定字典后Q对w为凹函数。梯度归一化为

\[
g_k=\frac{\sum_i L_{ik}/f_i+c_s/\pi_s}{m+\lambda},\qquad
\delta=\max(0,\max_kg_k-1).
\]

Σw_kg_k=1，目标最优值差≤(m+λ)δ。收敛要求相对目标变化≤1e−8及δ≤1e−4，最多5000轮。这个界针对固定学习中心下的权重目标；边际中心的多起点ECM仍是非凸估计，不能将整个自适应过程称为保证全局最优。

零状态正则的思想与[Stephens（2017）补充材料S.2中的Dirichlet形式惩罚](https://stephenslab.uchicago.edu/assets/papers/Stephens2017-supplement.pdf)有关；这里扩展到中介分析的三个复合零状态，并自行推导联合权重更新。数据驱动位置字典属于经验贝叶斯g-modeling的范畴，可参考[Efron的原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4196219/)。这些背景文献没有用于改变两套实验数据。

## 4. 后验与效应矩

每个成分的后验责任r_ik给出四状态概率，lfdr=γ00+γ10+γ01。使用原项目同一个lfdr_step_up筛选器。后验效应均值需改为

\[
b_{ik}=\mu_k+U_k(S_i+U_k)^{-1}(\hat\theta_i-\mu_k),\quad
C_{ik}=U_k-U_k(S_i+U_k)^{-1}U_k.
\]

按r_ik混合均值与二阶矩；E(αβ)=Σr_ik(b_αb_β+C_αβ)，产品方差继续用二元正态四阶矩。先验零方差但中心非零时，后验恰为对应点质量；无需求逆U_k。

## 5. 实验与使用范围

开发/确认/验证划分和筛选规则见 `ASHMED_OPTIMIZATION_PLAN.md`。第1–8次用于开发，第9–12次确认，第13–40次最终验证；原版与其他三方法也限制在同一验证重复中比较。所有候选与失败结果保留。锁定配置和源码指纹位于 `results/ashmed_optimization_20261005/locked_method.rds`。

学习中心、尺度、权重及回退只看观测摘要；真值只在开发评价、指标计算和事后解释时加入。无需重新生成数据。最终Power提高必须同时结合逐条件FDR、MCSE、区间及配对差，不以高Power掩盖FDR失控。

该修改针对有非零中心效应的摘要数据更灵活；对混合方向、严重错设、采样误差相关、非正态摘要等没有普遍优越性或FDR控制定理。二元结局继续标为Logistic正态摘要扩展，αβ属于条件系数乘积。后验SD忽略字典中心及混合权重的估计误差。

## 6. 工程及检查

- 原版插件未修改；新插件私有加载原数学例程，适配器版本含原插件MD5依赖，源码/配置/版本变化会使对应新缓存失效。
- 试验入口 `R/ashmed_optimization.R`，每个阶段的manifest带原data_id及分析重复，阶段进入新run ID，避免覆盖不同子集结果。
- `tests/check_adaptive_ashmed.R`以独立矩阵公式验证非零中心密度、共轭矩、已知正则目标最优解、原版等价开关与近零中心回退。
- 第四notebook展示结构失败、正则开发、确认、冻结配置和最终比较。`docs/ASHMED_ADAPTIVE_RUN_REPORT.md`记录实际结果。
