## 结论

用户对结果异常的判断有依据。主实验不是一个足够有区分度的方法比较：power 均值仅0–0.0222，某些条件经验 FDR 高于目标0.05。指标计算核对正确，但“方法调用成功”不等于“统计校准良好”。将这些图作为仿照论文的有效比较展示，并自动输出“功效最高的方法”，是不恰当的。notebook 已删除自动排名，补充逐次结果和本次解释。

## 1. 正文设定与源码设定不是同一效应强度

重新直接读取用户附件 MLFDR.pdf 第5页，第2.2节：非零 α=0.05τ+N(0,1/n)，非零 β=−0.5τ+N(0,4/n)。原作者 `results_in_paper/linear_model.R` 中 kap=1、psi=4，传入 R 的 rnorm 第三个参数，即标准差1和4，且没有随 n 缩放。正文与源码还存在直接效应分布差异，详见 SIMULATION_DESIGN.md。

| n=300、τ=1.9 的非零系数 | 主实验：正文设定 | 源码设定 |
|:--|--:|--:|
| α 均值 | 0.095 | 0.095 |
| α 标准差 | 0.0577 | 1 |
| β 均值 | −0.95 | −0.95 |
| β 标准差 | 0.1155 | 4 |

在 X~Ber(0.1)、中介噪声标准差为1时，α 回归标准误近似为 1/√(n×0.1×0.9)，n=300 时约0.192；主实验保存数据中对应中位标准误约0.18–0.21。真实非零 α 的平均 |α|/SE 约0.47–0.56，源码对照约3.94–4.75。主实验中的 β 在最大τ时已经很显著，但 α 仍是瓶颈。

对 n300/τ1.9 的每个场景与混合比例汇总，主实验真正 H11 路径中，只有约5.4%–12.5%的 α 检验能通过单个 p<0.05，β 检验全部能通过。正式的大规模中介筛选比“单个p<0.05”要求更高，所以功效接近0是有机制解释的。抽查还计算了使用已知 DGP 参数的近似高斯 local FDR：30份主数据均零拒绝。此项依赖正态近似和估计标准误，只用于诊断信号强度，不是有限样本校准保证，也不能加入正式方法比较。

因此不能将主实验的低功效解释为“这三种方法都差”。源码设定下单次功效约0.53–0.74，说明生成机制的选择直接改变实验难度。但不能由此认定论文笔误或认定其原图必然使用了某一设定；本项目没有完成原图生成过程的逐位复现。

## 2. FDR=0.6 到底发生了什么

主实验 binary/sparse/n300/τ1.9，5次重复的结果如下。所有非零发现都是假阳性，三种方法均没有真阳性。

| 重复 | HDMT发现数 | MDACT发现数 | MLFDR发现数 |
|:--|--:|--:|--:|
| 1 | 1 | 1 | 1 |
| 2 | 1 | 0 | 0 |
| 3 | 1 | 0 | 0 |
| 4 | 0 | 0 | 0 |
| 5 | 0 | 0 | 0 |

FDP=V/max(R,1)，经验FDR为逐次FDP的均值。因此 HDMT=(1+1+1+0+0)/5=0.6，另外两种方法=0.2。这不是60%的全部1000条路径都错了，也不是汇总程序算错。每次仅一个假发现时，FDP同样等于1。

不过，“只有5次重复”不能解释掉问题。进一步检查HDMT的零假设混合比例：

| 重复 | 实际H01比例 | 估计H01比例 | 实际H10比例 | 估计H10比例 | 原发现数 | 换入真实零假设比例后的诊断发现数 |
|:--|--:|--:|--:|--:|--:|--:|
| 1 | 0.060 | 0.225 | 0.048 | 0 | 1 | 1 |
| 2 | 0.045 | 0.008 | 0.057 | 0 | 1 | 0 |
| 3 | 0.043 | 0.00625 | 0.051 | 0 | 1 | 0 |
| 4 | 0.042 | 0.15556 | 0.053 | 0 | 0 | 0 |
| 5 | 0.046 | 0.14444 | 0.048 | 0 | 0 | 0 |

H01 表示 α=0、β≠0，仍属于“没有中介效应”的零假设。第2、3次错误拒绝均来自H01。对应路径的HDMT估计FDR分别为0.0350和0.0152；只换入实际零假设比例后，变为0.3295和0.1788，均不再通过0.05阈值。这给出明确的诊断证据：低估单边非零的零假设成分，会让阈值偏宽。第一重复的假发现仍保留，单次偶发假发现本身不能判断FDR控制失败。

这项使用真值的替换只用来定位原因，真实分析不能把真实混合比例提供给算法。HDMT与MDACT共用null_estimation；该模块在弱α情形下的估计不稳定值得进一步评估。MLFDR使用自己的EM估计，其第一重复也把H01路径错误识别为中介。仅凭这5次重复，不能估准该条件的总体FDR，也不能断言三种方法在其他设定均失控。

## 3. MLFDR 的默认搜索范围也不匹配

已安装 MLFDR 0.1.0 的 EM_fun 默认：

```r
kappa_int <- c(min(0.1, min(var_alpha)), max(10, max(var_alpha)))
psi_int   <- c(min(0.1, min(var_beta)),  max(10, max(var_beta)))
```

κ、ψ是非零系数的先验方差，不能混同回归系数估计的采样方差var_alpha、var_beta。抽查发现：

- 正文线性稀疏 n300 第一重复：α真实先验方差0.00333，默认下界0.03152，拟合κ=0.03158贴近下界；真实值位于允许范围之外。
- 正文线性密集 n300 第一重复：下界0.03195，拟合κ=0.03200；扩大范围后κ约0.0000463、拟合π11从0.0619变为0.1413，似然改善，但依然零拒绝。
- 源码线性密集 n300 第一重复：β真实先验方差16，默认上界10，拟合ψ=9.99993贴近上界；扩大范围后ψ=17.2386，似然从−1793.19改善到−1757.29。

诊断保持初始化和eps=.01不变，仅把两段搜索范围改为[1e−8,100]。5份抽查数据的拒绝数均未变化；正文 binary/sparse 第一重复的那个假阳性也未消失。这说明默认范围的确限制拟合，但它不是低功效和全部校准问题的唯一原因。没有因“调参数后看起来更好”而替换原结果。正式比较应预先确定数据尺度与合理范围，记录拟合参数、边界情况及初始化敏感性；不应按观测FDR或功效选择最有利参数。

## 4. 图和汇总应如何读

- FDR=0与power=0可能只是一次都不拒绝，不能作为既有用又校准良好的证据。
- 原图功效轴自动缩放，最高只有约0.022；线条差异大多来自极少数真发现，不能稳定排名。
- 5次重复的t区间仅是近似描述，5次全0导致零宽区间，不代表总体误差率已被精确证明为0。
- 源码对照每条件只1次；应称“单次FDP”，不能用0.03–0.10等数值声称FDR得到控制。
- 当前数据生成、OLS/GLM系数与方差、真值标签、拒绝后FDP/power计数已核对。检测到的问题主要属于设定强度、混合模型拟合与有限重复下的统计解释；工程成功检查不能替代统计有效性检查。

## 后续比较的建议

若目标是先得到一个接近作者代码的、便于新增方法的比较基准，可采用source_demo，将每条件重复增加到100或250，先执行线性模型、作者使用的稀疏n300/密集n100，再加入混杂和二元模型。源码设定仍应明确标为“基于作者代码”，不能称为完全复现正文。增加重复只改善精度，不会自动修复拟合偏差或FDR失控。

正文弱信号设定保留为困难场景，也应增加重复、检查MCSE、零假设比例和拟合边界。两种DGP独立汇总，使用同一数据给各算法，避免混合两者后作结论。只有在FDR校准可接受的条件下比较功效，才适合讨论新方法的优势。
