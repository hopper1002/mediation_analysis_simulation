# 当前比较的设计与统计实现

用户要求以原论文模型为主，并允许为形成合理的FDR和功效对比增强信号。本次使用Roy & Zhang (2026)第2.2节的线性、已测混杂、二元结局三种模型。作者代码用于理解接口及MDACT实现，未采用其标准差1/4的系数生成方式。

## 参数

m=1000，n=300，τ=1.3/1.5/1.9。稀疏状态概率(0.88,0.05,0.05,0.02)、密集(0.4,0.2,0.2,0.2)，顺序H00/H10/H01/H11。X~Ber(0.1)，已测混杂Z~N(0,1)，其路径系数独立U(0,0.5)。直接效应γ~N(1,0.5)，第二参数为方差；连续模型误差独立N(0,1)。非零β=−0.5τ+N(0,4/n)。

**与正文的唯一效应分布调整：非零α=0.35τ+N(0,1/n)，正文均值为0.05τ。** 模型结构、系数噪声和观察噪声不变。n=300、τ子集取自论文范围，40次重复为规模缩减。此设计标记为paper_adjusted；paper2026表示字面正文参数，source_code表示历史源码配置，不能混合汇总。

正文最大τ的α均值0.095，相比回归标准误约0.192很小。增强后均值0.455/0.525/0.665约为2.4/2.7/3.5个标准误，覆盖中等到较强信号，使方法的拒绝区域差异有机会体现。目的不是预设MLFDR获胜。

## 方法

HDMT调用已安装包null_estimation和fdr_est(exact=0)。MDACT保留作者的权重估计、1e−3下界、统计量及二分阈值搜索；只有F00数值积分替换为相同事件概率的解析面积。推导与核查在vendor/PROVENANCE.md和tests/test_mdact_cdf.R。

MLFDR默认paper_em后端实现论文第5.1、5.3节的四成分高斯混合模型。令a=√n αhat、b=√n βhat，采样方差为n×SE²，成分均值为(0,0)、(μ,0)、(0,θ)、(μ,θ)，相应非零维度增加先验方差κ/ψ。联合权重π00/π10/π01/π11自由估计，不强制两段状态独立。log-sum-exp计算后验，EM更新联合权重、共享非零均值和方差。

κ/ψ允许为0；上界由观测方差和采样方差确定，不用真实效应方差。3个固定初始权重为(.7,.1,.1,.1)、(.4,.2,.2,.2)、(.9,.035,.035,.03)，均不根据实际混合标签切换。均值按观察系数尾部初始化，方向变换仅用于初始化；均值可自由更新。起点按最大观测似然选择，既不看真实状态，也不看FDR或功效。

同一模型的package后端仍可调用已安装MLFDR::localFDR。paper_em是论文模型的数值实现，不能标成原包未修改输出。默认容差1e−4、最大2000迭代，未收敛会记录警告。fit_diagnostics.csv包含收敛、迭代、均值、方差和π；所有方法用同一套OLS/logistic估计。

local FDR为H00/H10/H01后验概率之和。按分数从小到大排列，选择累计均值≤q的最大合格集合；并列整组处理，零/全拒绝边界可用。q=.05对所有方法相同。它不是将结果FDP截到.05，也不是逐个lfdr≤.05。

## 评估和区间

逐次FDP=V/max(R,1)、power=S/A；FDR为FDP的平均。报告MCSE=SD/√B。大部分区间为近似t均值区间、截在[0,1]；当B次有界观测全部为0/1时，以每端0.025概率的保守端点界替代零宽区间。该边界对独立[0,1]观测有效，但一般t近似和多条件检查不是同时保证。

功效差异按同一case_id配对，报告MLFDR−HDMT、MLFDR−MDACT的差值、MCSE和区间，避免把独立标准误误用于配对数据。只有同时看FDR，更多发现才有比较意义。正文原图与本实验信号不同，不要求数值或所有条件的排名相同。
