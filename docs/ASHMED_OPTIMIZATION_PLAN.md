# ASHMED方法优化：开发与验证安排

日期：2026-10-05。只读取已经保存的两套数据，不生成或修改原始数据，保留原ASHMED及第三notebook。q保持0.05；新增方法标签`ASHMED_Adaptive`，不把修改版称为原论文实现。

## 固定的阶段划分

- 初步结构比较：每条件第1–3次重复，3次×36条件，共108份数据。尝试零中心独立尺度、学习中心但绑定尺度、学习中心并独立尺度，以及只使用学习中心的独立尺度字典；与原ASHMED作参照。
- 扩展开发：每条件第4–8次重复，5次×36条件，共180份数据。在较好的结构上测试总零状态伪计数λ=0/10/30/90；若需要新增结构，另记开发日志，仍限定在第1–8次。
- 小规模确认：第9–12次，共144份数据，只运行开发阶段选定的设置；如确认失败需要继续探索，记录此阶段已参与开发，并保留第13–40次不用于选型。
- 最终比较：锁定方法与选项后使用第13–40次，每条件28次，共1008份数据，与HDMT/MDACT/MLFDR比较，并保留原ASHMED参照。不按最终验证的真值结果再选一个更好版本。

这些历史重复此前用于原版方法比较，因此这是“未参与本轮修改版选型的验证子集”，并非新的外部数据或完全未被观察过的研究场景。方法仅在当前两套DGP上探索，不据此宣称普遍优于其他方法。

## 方法变化及选择原则

最初用开发子集内的一份线性密集数据核查实现时，发现“仅放开零中心尺度”的FDP达到0.541，而学习中心并继续保留零中心字典的FDP为0.121。这两个结果都不合格，未把高Power作为成功。加入“只使用学习中心字典”的结构候选，检查近零替代成分与精确零状态难以识别是否导致误报；结构阶段会保存所有这些尝试。

学习非零中心时只看观测系数/标准误。一个已知零成分加自由正态成分的边际模型提供每段中心；再将零中心多尺度与学习中心多尺度组成字典，H11允许两个尺度独立。点质量仅加入非零学习中心，避免与精确零先验重复。

零状态正则为λ/3乘以logπ00+logπ10+logπ01，对应状态Dirichlet先验的伪计数；不改变q。固定中心及字典后目标对联合权重为凹函数，保存优化误差与收敛轨迹。

所有候选、失败及警告均保存。开发筛选优先要求两套分别平均经验FDR≤0.06、最大条件经验FDR≤0.15，以及平均Power相比原版提高；在这些门槛内优先Power高的设置，接近时优先较轻正则。小样本门槛是开发筛选规则，不是FDR控制证明；最终使用28次重复的逐条件FDR、MCSE及配对差判断。

若没有候选满足门槛，会继续记录有依据的结构修改，并明确报告未达到的目标，不通过放宽q、挑种子或删除重复获得结果。估计方法不接收模拟真值；真值只用于开发评价及最终验证。
