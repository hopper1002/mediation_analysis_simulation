## 如何理解

四类路径中只有H11是真中介。另一段无效时，即使单段显著也属于复合零假设。新DGP的α、β固定且同向，MLFDR允许零先验方差的混合模型能利用效应方向及两段的联合密度；HDMT/MDACT使用p值及零假设混合。功效差异需结合FDR判断；结果只适用于所展示的分布。新旧数据的效应分布和分组比例不同，跨notebook的Power变化不是方法实现变好的证据。
